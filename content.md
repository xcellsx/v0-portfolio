## 01 / The Patient Problem

### The Cognitive Cost of Order.

> Traditional productivity systems fail neurodivergent (ADHD/Autism) brains because they rely on heavy visual friction. Red notification dots, infinite nested calendar menus, and manual micro-input forms create immediate executive dysfunction and task paralysis. The problem isn't a lack of organization; it's the steep energy tax required to establish it.

---

## Section 03 // The Core Hybrid System

**Protocol // Automated Chunking**

### Directing the Engine, Guarding the Interface.

#### Step 1: The Brain Dump Input
**INPUT LAYER // RAW CONTEXT**

A single, unconstrained text field designed for raw, chaotic thoughts. Zero formatting rules. Zero categorical stress.

#### Step 2: Ambient Processing
**PARSING CHAOTIC STRINGS // SEMANTIC SYNTAX MAPPING**  
**SUBSURFACE PROCESSING // TOKEN SEGMENTATION**

An intentional micro-moment of calm. Large, looping, low-poly geometries track the processing timeline while a background generative script delegates the heavy cognitive work of task breakdown.

#### Step 3: Crystalline Checklists
**DISPOSITION LAYER // ISOLATED MICRO-ACTIONS**

The output. Clear, non-threatening frosted glass cards displaying singular actions. Timeframes are automatically evaluated to prevent stress.

---

## Section 04 // Deep-Dive Component Systems

### Component 01 // The Sensory Shell

> I stripped away traditional corporate software patterns—such as persistent side menus, user profile avatars, and utility navigation rows—to preserve user energy. The design uses rigid, predictable layouts and semantic CSS spacing to guarantee an interface that functions as a predictable sanctuary.

### Component 02 // The Calendar Tapestry

> Color-coded charts often amplify stress. I built the calendar module around subtle shape markers rather than colored circles. This lets users map their commitments instantly without feeling overwhelmed by an intense wall of alerts.

## Cayra — 3D Model (2025)
**Tools:** Fusion 360  
**Disciplines:** Mechanical Engineering · Rapid Prototyping · Flight Dynamics

### ENGINEERING THE TOOLLESS FRAME.

The standard BetaFPV drone architecture is heavily reliant on micro-fasteners. A simple motor replacement requires removing 12+ screws, creating a maintenance bottleneck that creates significant downtime. The design challenge was to reimagine the airframe assembly to be completely toolless without sacrificing structural rigidity.

**Goal:** To democratize repairability. We re-engineered the chassis to utilize a central compression lock system. This allows the structural arms to be detached and swapped instantly by hand, converting a complex mechanical assembly into a friction-based modular system.

**Methodology:** Problem Identification → Redesign Ideation → Iterating Design → Flight Validation

**Evolution:**
- **ANALYSIS: PAIN POINTS** — Baseline Analysis. The OEM frame required high-precision tools for disassembly.
- **V1: WEIGHT FAILURE** — First toolless concept exceeded motor thrust capacity.
- **V2: FLIGHT FAILURE** — Weight optimization introduced structural flex and flight instability.

**Final Assembly:** The definitive toolless configuration resolving weight and stability failure modes through unified friction-lock architecture.
